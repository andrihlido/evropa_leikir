# Evrópuleikir

Sjö leikir úr kennslubókinni *Evrópu* fyrir Vestur-, Austur- og Suður-Evrópu.

## Uppsetning á GitHub Pages
1. Hladdu öllu innihaldi möppunnar upp í nýja geymslu (repository) á GitHub.
2. Farðu í **Settings → Pages**, veldu **Deploy from a branch**, greinina `main` og möppuna `/ (root)`.
3. Síðan birtist eftir um eina mínútu á `https://<notandanafn>.github.io/<heiti-geymslu>/`.

## Uppbygging
- `index.html` – forsíða
- `leikir/` – einn HTML-skrá fyrir hvern leik
- `js/gogn.js` – **allt efnið**: lönd, þrautir, orð, atburðir og fullyrðingar. Breyttu hér til að bæta við efni.
- `js/sameiginlegt.js` – svæðaval og hjálparföll
- `css/still.css` – útlit

Árangur nemenda (met, sigrar) vistast aðeins í vafra hvers nemanda. Engin innskráning.
